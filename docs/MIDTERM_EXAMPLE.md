# 恺英网络 MIDTERN 分析样例

按照我们给 AlphaBee 定下来的新逻辑，恺英网络和迈瑞医疗、工业富联又是第三种完全不同的状态。

我的结论先说：

> **截至 2026 年 8 月 22 日，我认为恺英网络大致处于 S2“证据确认”向 S3“共识扩散”过渡的阶段。**
>
> 它比迈瑞更靠后，比工业富联更靠前。当前最大的优势是：**基本面已经明显加速、2026 盈利预期仍在小幅上修、估值并不贵。**
>
> 但最大的风险也很明确：**Q1 的高利润增速含有较大的非经常性收益，新游增长很强但买量成本也很高，核心问题是新游能否从“流水爆发”真正转成“持续利润释放”。**

所以，如果按照“预期差开仓 → 证据加仓 → 共识持有 → 透支减仓”的体系，我目前会把恺英网络定义为：

[
\boxed{\text{可以开仓，且比工业富联更符合新资金介入逻辑}}
]

但它不是迈瑞那种“低位反转型”机会，而是：

[
\boxed{\text{成长确认型机会}}
]

[

[

这意味着恺英的增长逻辑已经发生了明显变化：

以前更多依靠：

> 老传奇产品 + 存量运营。

现在逐渐变成：

[
\text{老产品现金流}
+
\text{传奇+X新游}
+
\text{996传奇盒子}
+
\text{新品管线}
]

这比单纯一款爆款游戏更重要。

# 四、《烈焰觉醒》是目前最重要的验证

公司披露：

> 《烈焰觉醒》Q1贡献约10亿元收入。

而且公司认为这初步验证了：

[
\boxed{\text{传奇 + X}}
]

模式。([新浪财经VIP][4])

这其实是恺英当前 Thesis 的核心。

以前市场容易认为：

> 恺英=传奇类存量公司。

如果“传奇+X”真的可以成立，那么商业逻辑变成：

```text
传奇IP流量基础
      +
成熟付费模型
      +
新的题材/玩法
      ↓
不断推出新产品
```

那么它就不是单款游戏生命周期问题，而是：

> **一套可重复的产品工业化能力。**

如果这个逻辑后面继续被两三款产品验证，估值体系会比纯传奇公司更稳定。
