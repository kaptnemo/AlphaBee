# 参数变更记录（append-only）

本文件是 `params/registry.yaml` 的**追加式**变更记录（设计 §4.10「校准纪律」）。
只允许在文件末尾追加新条目，**不得修改或删除历史条目**（历史是审计证据）。

登记规则：

- 改 `registry.yaml` 的**默认值** = 行为变更：必须在本文件追加一条，并在
  `docs/roadmap/ROADMAP.md`「行为变更登记」表追加一行（依据/影响面/回滚）；
- `active` 状态需要证据（backtest 或 ≥50 真实帧人工评审）；证据不足只能是
  `placeholder`/`shadow`，**不得宣称"已校准"**；
- `frozen` 参数只允许 experiment / 显式 overrides 覆盖，不得写进 `config.yaml`；
- 回滚方式必须可执行（改回旧值 + 重跑指纹/回归），不能只写"回滚"二字；
- 每条记录必须写清样本量：真实帧 / 实验帧 / 合成用例各多少；样本不足时
  明确写"不足，不宣称校准"。

条目格式（逐条复制并填写，**不要**删除字段）：

```markdown
## YYYY-MM-DD / <参数 id>
- 旧值 → 新值: <旧值> → <新值>
- 样本: 真实帧 N（实验帧 M / 合成 K）；<是否充足，不足时写"不足，不宣称校准">
- 指标变化: <具体字段与数值变化；影子/回放输出为准，不写"略有提升"这类不可复现结论>
- 是否达标: <是/否 + 判据>
- 回滚: <改回旧值 + 重跑什么>
- owner: <责任人>
```
